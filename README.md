# DBMS-Assignment-5-6-7

A beginner-friendly DBMS assignment based on **SQL Querying, Aggregation & Joins**. This assignment focuses on practicing SQL queries using the `orderdb` database, including filtering, sorting, grouping, aggregation, and different types of joins.

## Assignment Overview

The assignment involves working with the `orderdb` database and performing SQL queries on customers, products, and orders.

The work is divided into three main parts:

1. **SQL Querying**
2. **Grouping & Aggregation**
3. **Joins**

The assignment contains a total of **18 SQL queries**, with 6 questions in each part.

## Database

### orderdb

The database contains the following main tables:

* **CUSTOMERS**
* **PRODUCTS**
* **ORDERS**

## Tables and Attributes

### CUSTOMERS

* `customer_id` — Primary Key
* `customer_name`
* `city`
* `country`

### PRODUCTS

* `product_id` — Primary Key
* `product_name`
* `category`
* `price`

### ORDERS

* `order_id` — Primary Key
* `customer_id` — Foreign Key
* `product_id` — Foreign Key
* `order_date`
* `quantity`

## Part 1 — SQL Querying

This part focuses on retrieving and filtering data using SQL queries.

The following queries were performed:

1. Display customers from India
2. Display Electronics products with price greater than 10000
3. Display orders placed in January 2024
4. Display customers who are not from India
5. Search products whose name starts with `L` or belong to the Stationery category
6. Display orders where quantity is greater than 1

## Part 2 — Grouping & Aggregation

This part focuses on using aggregate functions and grouping data.

The following queries were performed:

1. Calculate total quantity ordered for each product
2. Count orders for each customer and display customers with more than one order
3. Calculate total revenue for each product category
4. Calculate average product price for each category
5. Find the customer or customers with the maximum number of orders
6. Calculate total quantity ordered for each month

## Part 3 — Joins

This part focuses on combining data from multiple tables using different types of joins.

The following queries were performed:

1. Display complete order details using INNER JOIN
2. Display all customers and their orders using LEFT JOIN
3. Display all products and their orders using LEFT JOIN
4. Display all possible customer-product combinations using CROSS JOIN
5. Calculate total revenue generated by each customer
6. Display customers who have never placed an order
